# FLA Task 3 - PDA and CFG Applications

## Project Overview

This project demonstrates three applications of
Pushdown Automata (PDA) and Context-Free Grammar (CFG)
using Python.

## Case Studies

1. Balanced Parentheses Checker
2. Arithmetic Expression Validator
3. Binary Palindrome Checker

## Technologies

- Python 3
- PyCharm
- Pushdown Automata
- Context-Free Grammar

## Project Structure

- main.py
- balanced_parentheses.py
- arithmetic_expression.py
- palindrome_checker.py
- README.md
- diagrams/
- screenshots/

## How to Run

1. Open the project in PyCharm.
2. Open main.py.
3. Right-click and select Run.
4. Select an application from the menu.
5. Enter the required input.

## Features

- Interactive menu
- Stack-based PDA simulation
- CFG-based arithmetic parsing
- Nondeterministic PDA simulation
- Accepted and rejected test cases
- Automated testing

## Conclusion

This project demonstrates the use of PDA and CFG
in nested bracket validation, arithmetic syntax
validation and palindrome recognition.
